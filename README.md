# Python Games Collection

A collection of Python games built over several years using Processing (Python mode) and Turtle.
These projects explore game loops, collision detection, state management, and interactive graphics.

## Featured Games
- Asteroids
- Atari Breakout
- Frogger
- 2048
- Fruit Ninja
- Snake
- RPG
- Wordle

## Tech Used
- Python
- Processing (Python Mode)
- Turtle Graphics

## Notes
These games were created as learning projects and reflect my progression over time.
